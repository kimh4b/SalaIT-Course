# SalaIT - Full-Stack Web Development Course

This repository contains my learning materials, exercises, assignments, and projects from the SalaIT Full-Stack Web Development Course.

## Technologies Covered

- HTML5
- CSS3
- JavaScript (ES5 & ES6)
- TypeScript
- Angular
- NestJS

## Repository Structure

- `HTML Lesson/` – HTML lessons and exercises
- `Javascript Lesson/` – JavaScript exercises and assignments
- `Typescript-Lesson/` – TypeScript lessons and practice
- `Angular-Lesson/` – Angular lessons

## Purpose

To develop my programming skills, strengthen my understanding of full-stack web development, and gain practical experience through hands-on exercises and projects.
